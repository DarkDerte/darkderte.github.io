## La idea

Abrir un archivo de texto o Markdown y leerlo con una vista limpia. El archivo se procesa localmente y no se almacena fuera del dispositivo.

La primera versión prioriza texto plano y una vista previa Markdown sencilla. No ejecuta contenido HTML incrustado ni convierte el visor en un editor complejo.

## Principio

Un archivo personal no debería tener que viajar a un servicio remoto solo para poder leerse.
