## Qué hace

`onepage` convierte documentos Markdown en páginas HTML estáticas con estilos sencillos. El resultado se puede alojar en cualquier servidor de archivos estáticos.

No requiere base de datos, servidor de aplicación ni proceso de desarrollo permanente. Los temas y plantillas se mantienen deliberadamente limitados para que el HTML generado sea fácil de entender y modificar.

La salida no incluye JavaScript salvo que el autor lo añada expresamente.
