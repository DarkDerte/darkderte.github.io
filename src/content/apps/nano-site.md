Este sitio es la demostración práctica de todo lo que defiendo.

- **Estático de verdad**: Astro genera HTML puro. El JavaScript es opcional.
- **Sin rastreadores**: no hay analytics, no hay telemetría, no hay consent managers.
- **Ligero**: la página principal transfiere menos que un anuncio de un periódico digital.
- **Accesible y legible**: tipografía de sistema, alto contraste, sin animaciones innecesarias.

Si una web se tarda en cargar, es porque alguien decidió que no importaba.
